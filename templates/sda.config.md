# Configuración SDA

> Completa estos datos al empezar a usar la metodología. `/sda-sprint` los lee y los mantiene.
> El framework e2e es obligatorio porque el test es el contrato de cada HU.

## Tests e2e
- **framework**: <Playwright | Maestro | Cypress | Detox | ...>
- **comando**: <ej. `npm run test:e2e`>
- **directorio**: <ej. `e2e/`>
